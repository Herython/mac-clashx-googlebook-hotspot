# 热点转发工具箱

## 启动

1. 用 USB 连接 iPhone，开启个人热点。确认 Mac 的「iPhone USB」已连接。
2. 打开 ClashX，确认代理端口为 `127.0.0.1:7890`。
3. 在「系统设置 → 通用 → 共享 → 互联网共享」中，将 iPhone USB 共享给 Wi-Fi。热点名称和密码可在 Wi-Fi 选项中查看。
4. 双击「启动透明代理.command」，输入管理员密码。看到 `READY` 后保持终端窗口打开，再让设备连接热点。

## 关闭与排障

- 在转发终端按 Control+C，看到 `Temporary rules removed` 后关闭互联网共享。
- 如果原终端异常退出，可运行「维护/应急恢复普通热点.command」清理工具的临时规则。
- 如果无法启动，检查热点网关是否为 `192.168.2.1`，以及 ClashX 是否正在监听 `7890`。运行日志位于「运行记录」。
- 如果设备时间有误，先确认 Mac 时间正确，再让设备重新联网或重启以触发校时。

热点的 IPv4 TCP 流量经 ClashX 转发。普通 DNS 转为加密 DNS 查询，NTP 由 Mac 在本地应答。热点 IPv6 和其他 UDP 流量受限。
