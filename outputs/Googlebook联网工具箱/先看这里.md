# Googlebook 联网工具箱

适用设备：这台 Mac + ClashX + iPhone USB 上网 + Wi-Fi 热点。
2026 年 11 月 2 日已帮助 Lenovo Googlebook 完成首次激活；设备时间错误通过临时校时解决。

## 下次启动

1. 用 USB 连接 iPhone，开启「个人热点 → 允许其他人加入」，解锁并确认信任。
2. 在 Mac 网络设置确认「iPhone USB」已连接。保持 iPhone USB 在网络服务顺序中优先于 Wi-Fi。
3. 启动 ClashX，选择可用节点。程序使用现有的 `127.0.0.1:7890` 代理端口。
4. 在「系统设置 → 通用 → 共享 → 互联网共享」中，来源选择「iPhone USB」，共享给「Wi-Fi」，开启共享。
5. 双击本文件夹的「启动透明代理.command」，输入 Mac 登录密码（输入时不显示字符）。看到 **READY** 后保持终端窗口打开。
6. Googlebook 连接下方热点。不通时先断开重连；若设备时间错误，可重启设备触发自动校时。

热点名称：**MacBook Air**
热点密码：在 Mac「互联网共享 → Wi-Fi 选项」中查看；本机备忘见未纳入 Git 的「本机连接信息.local.md」。
热点网关：**192.168.2.1**（当前程序固定使用此网段）

Mac 应保持唤醒，iPhone USB 和 ClashX 应持续运行。

## 正常关闭

1. 在转发终端按 **Control+C**，等出现 `Temporary rules removed` 后再关闭窗口。
2. 关闭 Mac 的「互联网共享」。
3. 重新连接正常 Wi-Fi，再断开 iPhone USB；不需要代理时可退出 ClashX。

不要只依赖强制退出终端来清理规则。

## 出错时

- 没有 READY：查看终端提示，不要反复开启多个副本。
- 提示热点未启动或网关错误：确认来源为 iPhone USB、出口为 Wi-Fi，热点网关为 192.168.2.1。
- 提示端口占用或 anchor 已存在：优先回到原转发终端按 Control+C。
- 原终端丢失、异常退出后网络不通：双击「维护/应急恢复普通热点.command」。它只清除本工具的临时规则；如果原进程还在运行，仍需在原终端按 Control+C 结束。
- 设备时间不对：确认 Mac 时间正确，再启动本工具并重连或重启 Googlebook。
- 要排查问题：把「运行记录」中的最新日志提供给我。日志含访问域名和局域网地址，请勿公开分享。

## 文件说明

- **启动透明代理.command**：以后双击此文件启动。
- **hotspot-proxy.py**：核心程序，需与启动文件放在一起。
- **运行记录/**：下次运行生成的日志、规则及启动前 pf 状态快照；请保留这个文件夹。
- **维护/**：异常退出时恢复普通热点的工具。
- **历史诊断/**：本次成功激活的日志与旧说明，仅供回看，无需运行。历史 pf 快照不能直接拿来覆盖系统规则。

整个「Googlebook联网工具箱」可一起复制或移动到其他普通文件夹，内部文件请保持相对位置。不要放进 .app 包内。若复制到另一台 Mac，需要重新检查软件、接口与网关。

## 功能与限制

热点 IPv4 TCP 通过现有 ClashX；DNS 经 ClashX 使用 Google 加密 DNS；普通 NTP 校时请求由 Mac 本地应答。ClashX 仍按其当前规则选择出口。

热点 IPv6 及除 DNS、DHCP、校时之外的 UDP 被阻止；不是完整 TUN，不支持任意 UDP 应用或 QUIC。适合本次联网激活及常规 TCP 上网场景。

不安装新客户端，不写入 /etc/pf.conf，不改 /dev/pf 权限，不设置开机自启。规则退出时撤销；重启 Mac 或重新开启系统共享后，需重新启动本工具。
